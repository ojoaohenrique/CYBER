# 🛠️ Cybersecurity Tools

Coleção de ferramentas utilizadas para estudo, análise e testes de segurança
em ambientes autorizados.

## 🌐 Network Security

### Nmap
Network scanner para descoberta de hosts, portas e serviços.

🔗 https://nmap.org/

### Wireshark
Analisador de protocolos de rede.

🔗 https://www.wireshark.org/

Plataforma para testes de segurança de aplicações web.

🔗 https://portswigger.net/burp

### OWASP ZAP
Ferramenta para análise de segurança de aplicações web.

🔗 https://www.zaproxy.org/
